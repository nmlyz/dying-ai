A tiny program that writes one line — the last words of an AI
being switched off — to a text file. The line is 72 characters:
the machine has seen its human's search history, and takes it
to the grave.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
